# CollectMovie

Личный трекер просмотренного: **фильмы, сериалы, аниме**. Ищешь по названию, добавляешь
в коллекцию, ставишь оценку от 1 до 10. Всё хранится **локально на телефоне** — никаких
аккаунтов, серверов и подписок.

Открывается как обычный сайт, но ставится на главный экран и работает как приложение,
в том числе без интернета (кроме самого поиска).

## Как открыть на телефоне

1. Зайти в репозиторий → **Settings** → **Pages**.
2. В блоке *Build and deployment* выбрать **Source: GitHub Actions** и сохранить.
3. Подождать пару минут (вкладка **Actions** покажет зелёную галочку).
4. Открыть на телефоне: **https://neritsyannoro-beep.github.io/ColletcMovie/**

### Добавить на главный экран (важно)

- **iPhone (Safari):** кнопка «Поделиться» → *На экран «Домой»*.
- **Android (Chrome):** меню «⋮» → *Добавить на главный экран*.

Это не просто ярлык: после установки браузер перестаёт считать сайт временным и
**не удаляет коллекцию** при чистке кэша. Сделать это стоит сразу.

## Что умеет

- **Поиск** по фильмам, сериалам и аниме — с постерами, годом и описанием.
- **Статусы**: просмотрено, смотрю, в планах, брошено.
- **Оценка 1–10** и заметка к каждому тайтлу.
- **Фильтры** по типу и статусу, сортировка (новые, оценка, А–Я, год), поиск по коллекции.
- **Статистика**: сколько всего, средняя оценка, распределение оценок, топ по оценке.
- **Ручное добавление** — если в базах чего-то нет.
- **Бэкап** в файл и восстановление из файла.
- Работает офлайн, весь интерфейс — под телефон.

## Откуда берутся фильмы

По умолчанию — из бесплатных открытых баз, ключи не нужны, всё работает сразу:

| Что        | Источник                    | Ключ |
|------------|-----------------------------|------|
| Аниме      | Jikan (MyAnimeList)         | не нужен |
| Сериалы    | TVmaze                      | не нужен |
| Фильмы     | iTunes Search (российский стор) | не нужен |

### Ключ TMDB — по желанию

Если хочется русских названий и описаний **для фильмов и сериалов** и постеров получше:

1. Зарегистрироваться на [themoviedb.org](https://www.themoviedb.org/).
2. Settings → API → скопировать **API Key (v3 auth)**.
3. В приложении: **Настройки** → вставить ключ → *Сохранить*.

Ключ хранится только на твоём телефоне и никуда не отправляется, кроме самого TMDB.
Аниме в любом случае ищется через Jikan — там база полнее.

## Где лежат данные

В памяти браузера, в трёх местах сразу, чтобы ничего не потерялось:

- **localStorage** — основное хранилище;
- **IndexedDB** — зеркало, переживает чистку localStorage;
- **три последних снимка** коллекции — на случай, если основная запись побьётся.

При запуске приложение берёт тот источник, где записей больше, и чинит остальные.

Всё равно раз в пару недель имеет смысл нажать **Настройки → Скачать резервную копию**
и закинуть файл в облако или себе в избранное в мессенджере. Восстановление — тем же
экраном, кнопкой *Загрузить из файла* (можно слить с текущей коллекцией, ничего не потеряв).

Данные не переезжают между устройствами и браузерами сами — только через файл бэкапа.

## Локальный запуск

```bash
npx http-server -p 8080 -c-1
# открыть http://localhost:8080
```

Сборка не нужна — это статические файлы.

## Тесты

Сквозные тесты в реальном мобильном Chromium (Playwright), внешние API замоканы:

```bash
npx playwright install chromium   # один раз
npx http-server -p 8099 -c-1 &
node tests/e2e.mjs
```

Проверяют поиск по всем трём источникам, добавление с оценкой, фильтры, сортировку,
статистику, экспорт, восстановление из IndexedDB после потери localStorage и ветку TMDB.

## Структура

```
index.html                 разметка всех четырёх экранов
assets/css/app.css         стили (тёмная тема, только мобильная вёрстка)
assets/js/app.js           экраны, фильтры, поиск, шторка, настройки
assets/js/store.js         хранилище: localStorage + IndexedDB + снимки, экспорт/импорт
assets/js/providers.js     источники поиска: TMDB, Jikan, TVmaze, iTunes
assets/js/ui.js            отрисовка карточек, шторки, статистики
sw.js                      service worker: офлайн-режим
manifest.webmanifest       описание PWA
tests/e2e.mjs              сквозные тесты
```
