Коллекция лежит в памяти браузера (localStorage + IndexedDB). Делай бэкап раз в пару недель — файл можно закинуть в облако или себе в мессенджер.

TMDB API-ключ необязательно

Без ключа поиск фильмов и сериалов работает через бесплатные базы (iTunes и TVmaze) — названия в основном английские. С ключом TMDB получишь русские названия, нормальные постеры и описания.

Где взять: themoviedb.org → регистрация → Settings → API → «API Key (v3 auth)». Бесплатно, 1 минута. Ключ хранится только на этом телефоне.
